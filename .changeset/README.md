# Changesets

This directory is used by [Changesets](https://github.com/changesets/changesets) to manage versioning and changelogs for this monorepo.

## Usage

```bash
# Create a new changeset
npx changeset

# Version packages based on changesets
npx changeset version

# Publish packages
npx changeset publish
```

For more information, see the [Changesets documentation](https://github.com/changesets/changesets/blob/main/docs/intro-to-using-changesets.md).
